Acessar o SJP GEO

Funciona diretamente no Android, sem Replit, servidor ou API. Dados guardados apenas neste navegador. Não use dados reais.

Modo independente: as alterações são salvas neste navegador. Outros celulares não recebem atualizações. O mapa mostra somente posições GPS registradas neste dispositivo; sem posição, não inventa coordenadas.

Mapa operacional

Visualização esquemática sem mapas externos. Posições reais aparecem apenas quando o técnico autoriza o GPS e este navegador as recebe. Sem GPS, o técnico aparece como sem localização.

Minhas missões

Aguardando início automático do GPS…

📍 Localização iniciada automaticamente ao entrar no perfil técnico. Não há controle para desligar o envio durante a sessão. Autorize o acesso quando o Android solicitar.

O navegador/Android pode suspender o GPS com a tela bloqueada, sem sinal ou se a permissão for revogada nas configurações. Esta versão HTML não garante rastreamento contínuo, mesmo sem botão para desligar.
